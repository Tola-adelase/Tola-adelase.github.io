01 / The question

Can short titles reveal
meaningful themes?

Topic modelling groups patterns in text without training on a target class. The project explores whether three different approaches can produce useful themes from a varied collection of Medium article titles.

The notebook loads a table with category, title, subtitle and a subtitle-truncation flag, but the modelling input is the title field only. Category labels are not used as supervised targets.

My work covers text preparation, a shared dictionary and bag-of-words corpus, model comparison, coherence evaluation and exploratory visualisations.

02 / Preparing text

From headlines to a shared vocabulary.

01 / SAMPLE

Work with 8,000 titles.

The source table contains 126,418 rows and no missing titles in the saved checks. The notebook samples 8,000 rows before constructing the corpus.

02 / NORMALISE

Reduce avoidable noise.

Titles are lowercased and tokenised with an alphabetic-word pattern. English stop words, selected custom words and single-character tokens are removed; tokens are lemmatised.

03 / REPRESENT

Build the corpus.

The cleaned sample produces a Gensim dictionary with 9,585 unique tokens. Each title is represented as a bag of word counts for the three models.

The random sample is not given a random_state, so the exact 8,000-title selection is not reproducible from the code alone. The original CSV is referenced through a local path and is absent from the public repository.

04 / Quantitative evidence

A higher coherence score.
A more complicated judgement.

HDP leads on the saved metric.

The notebook reports c_v coherence of 0.7428 for HDP, 0.5129 for LDA and 0.4194 for LSA. These use the same sampled texts for evaluation.

That makes HDP the highest-scoring approach in this recorded run. It does not establish a general winner: topic complexity differs, sampling is unseeded, and there are no repeated-run comparisons or human quality ratings.

The notebook’s later comparison chart uses manually entered, truncated scores. This portfolio chart uses the more precise values printed by each model’s coherence evaluation.

06 / Interpretation

Use the metric to investigate,
not to end the investigation.

No deployment winner yet.

HDP’s saved score makes it worth investigating further. Before selecting it for a tagging or discovery workflow, I would pair coherence with human review, topic stability and representative-title checks.

LDA’s displayed keywords offer some recognisable themes, but that is a qualitative observation—not proof that it outperforms HDP or LSA in a user-facing task.

Article organisation and content discovery are potential uses of this work. The project does not measure search quality, recommendation performance, production latency or business impact.

07 / What I would strengthen

Make the next comparison fairer.

REPRODUCIBILITY

Fix the sampled input.

Record the dataset version, save the sampled IDs, seed all stochastic steps and document package versions. Repeat the comparison across seeds.

EVALUATION

Check usefulness with people.

Review representative titles per topic, assess stability and duplicate themes, and compare against a simple baseline. Test whether longer text improves the outcome.

VISUAL VALIDITY

Align charts with their data.

Rebuild topic vectors using explicit topic IDs before t-SNE. Correct length and topic-specific plots before presenting them as evidence.

These are proposed improvements. The original notebook is unchanged, and no new model training is claimed.
