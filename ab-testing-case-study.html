01 / The decision

A redesign needs
evidence to launch.

The business question was whether a new landing page increased the proportion of users who became paying customers. The options were to launch the new page, retain the existing page or gather more evidence.

In the project, I cleaned the experiment records, compared conversion rates, simulated a null distribution, performed a two-proportion z-test and explored logistic regression with country interactions.

This portfolio review checks the saved notebook outputs and independently verifies the main cleaning steps and rate comparison against the source CSV. The regression extensions have not been rerun.

What I did

I cleaned the experiment records, compared conversion rates and used hypothesis tests to assess the launch question. I also explored logistic regression in the original Udacity project. For this portfolio, I separated the observed effect from uncertainty and made the main calculation independently checkable. The dataset and project brief were supplied by Udacity.

BINARY OUTCOME

Compare like with like.

The primary outcome is converted: 1 for a conversion and 0 otherwise. Each rate uses the number of analysed users in its own group as the denominator.

Excluding mismatched assignments follows the course approach, but could introduce selection bias. A production review should investigate those mismatches and compare with an intention-to-treat analysis before treating the result as causal.

03 / Observed results

The new page did not show an uplift.

A small negative point estimate.

The old page converted 12.04% of analysed users; the new page converted 11.88%. That is an observed difference of −0.158 percentage points, or about −1.31% relative to the old-page rate.

These are two ways to express the same difference. Percentage points describe the absolute gap between the rates; relative change scales that gap by the control rate.

The new page’s lower observed rate alone does not demonstrate that the new page is worse. Sampling uncertainty matters.

04 / Statistical uncertainty

No demonstrated improvement.
Not proof of equality.

Test the launch question directly.

The one-sided test asks whether the new page improves conversion: H₀: p(new) ≤ p(old); H₁: p(new) > p(old).

At the boundary of the null, a pooled two-proportion z-test gives p = 0.9051. That does not meet the project’s 5% significance threshold for an uplift.

The p-value is a probability of a result at least as favourable to the uplift hypothesis under the boundary-null model. It is not the probability that the new page is worse or that the null hypothesis is true.

The interval is newly calculated from the reported counts using an independent-binomial normal approximation. It describes a range of effects compatible with that model, not a 95% probability assigned to the fixed true effect.

05 / A second analytical lens

Regression supports the same cautious decision.

The notebook’s page-only logistic regression reports a treatment coefficient of approximately −0.015 and a two-sided Wald p-value of approximately 0.190. That is consistent with the two-sided version of the rate comparison, which gives approximately 0.190.

The p-values differ from the one-sided uplift test because they answer different hypotheses. Logistic regression does not establish identical conversion probabilities.

The country-by-page interactions are not individually significant in the stored model. Those exploratory results do not prove that the page performs equally in every country; subgroup uncertainty and multiple comparisons still matter.

06 / Recommendation

Keep the existing page for now.

Do not launch on an unproven uplift.

The experiment provides insufficient evidence that the new page increases conversion. Retaining the current page is the defensible choice when the stated launch criterion is a demonstrated conversion improvement.

This recommendation does not claim a measured cost saving or rule out other benefits of the redesign. No revenue, implementation-cost or user-experience evidence was assessed in this case study.

BEFORE ANOTHER TEST

Define a worthwhile effect.

Agree the minimum conversion uplift that would justify the change. Set the sample-size and stopping plan before collecting more observations.

BEFORE A CAUSAL CLAIM

Audit the experiment.

Check assignment integrity, exposure logging, sample balance, outcome windows and the effect of removing mismatched records.

BEFORE A BUSINESS CASE

Add the decision context.

Weigh conversion against revenue, costs and relevant guardrails. More data is useful only if the remaining uncertainty could change the decision.

07 / What this project demonstrates

This project connects data-quality checks, probability, hypothesis testing and logistic regression to a practical recommendation. The portfolio review strengthens the original write-up by separating effect size from significance, correcting p-value interpretation and showing uncertainty explicitly.
