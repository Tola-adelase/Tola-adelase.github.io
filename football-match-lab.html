The question

How can an interactive tool make different contributions in the same match easier to explore, while keeping the context visible?

Source and preparation

StatsBomb Open Data, match 3869685. A Python script reads events and lineups from a pinned source revision, checks unique event IDs, excludes shootouts and goalkeepers, and aggregates actions by player and period. Only analytical summaries are published; raw event files are not redistributed.

Metric definitions

  • Completed passes: pass events without a recorded outcome. Completion = completed / attempted passes. No attempts gives “—”.
  • Shots and goals: shot events and those with outcome Goal. The penalty checkbox changes shots, goals, xG and shot zones only.
  • xG: sum of StatsBomb’s supplied shot probabilities. It describes recorded chance quality. I did not train this model.
  • Successful dribbles: Dribble events with outcome Complete. Pressures: recorded Pressure events, not necessarily possession won.
  • Shot zones: source x = 80–100 or 100–120, each split into three equal y bands. The display rotates the attacking third so the goal is at the top. These are aggregate zones, not exact locations.

Checks and limits

The full summaries reconcile to 30 shots and six goals (3–3), excluding shootouts. Period counts add back to match totals. Values are rounded only for display. A single match is an unrepresentative sample; this is descriptive analysis, not a prediction, player ranking or recruitment recommendation.
